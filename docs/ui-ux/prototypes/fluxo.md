# Fluxo de interação

Adicionar: preencher campos → validar nome/telefone → criar contato → atualizar tabela.

Editar: selecionar linha → alterar campos → salvar edição → atualizar tabela.

Remover: selecionar linha → solicitar remoção → confirmar → atualizar tabela.

Buscar: digitar nome → filtrar tabela. Limpar a busca mostra todos os contatos.
