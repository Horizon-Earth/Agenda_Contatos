# NetBeans e Scene Builder

Abra a raiz com pom.xml como projeto Maven. Use F6 para executar. Configure Scene Builder em Tools → Options → Java → JavaFX e abra resources/com/mycompany/agendacontatos/primary.fxml.

Se a execução indicar Java ausente, selecione uma plataforma JDK 17+ nas propriedades. Se o FXML não for encontrado, execute Clean and Build e confira a configuração resources no pom.xml.
